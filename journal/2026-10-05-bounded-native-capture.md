# Bounded native-log capture and supervision

A curator draft attempted incremental collection but still read to a growing EOF, accepted arbitrary timestamp strings, and checked only the first block for changes. The supervisor held it before real-log use and implemented a metadata-only collector. Historical draft artifacts were retained privately.

The replacement hashes an initial fixed-size baseline without interpreting conversation contents. Later receipts bind source identity, native session, byte ranges, complete prefix hashes and the preceding receipt digest. Allowlisted event counts and normalized valid timestamps are the only parsed output. Incomplete records wait for completion; oversized records are counted without keeping their text. Replacement, truncation and previously captured-prefix mutation hold the generation. Atomic publication and a single-writer lock protect cooperative operation. This is integrity bookkeeping, not adversarial protection against the same user changing programs or permissions.

Seven fixtures passed: baseline does not parse; sentinel-bearing payloads and invalid timestamps are withheld; mutation after the first4KiB is rejected; truncation/replacement preserve the old generation; partial UTF8 is counted once after completion; oversized records stay bounded; concurrent append stays outside the observed-size snapshot; and interrupted state publication preserves previous state. Several checks share fixtures, so seven tests are not seven independent field deployments. Source: [collector](../workbench/native_capture.py) and [tests](../tests/test_native_capture.py).

The private pilot captured initial receipts for five registered log sources, including compact/full exports of one curator session. Five sources do not mean five independent agents. No raw conversations, tool arguments, tool results or private reasoning are exported by this collector. Private paths and session identities remain in private receipts; those receipts must not be published without redaction. Event counts do not prove task completion, correctness or an agent reading a message.

Supervision also caught an evaluator test harness waiting indefinitely for JSON on standard input. The supervisor verified and terminated only that child process, saved a recovery receipt and explained the failure through the existing mail and visible Terminal relay. The evaluation session continued. This demonstrates a bounded recovery in one pilot, not a general efficiency claim.

Confidence is high for the executed fixture behaviors, moderate for broader native-log interoperability, and unestablished for adversarial integrity or efficiency gains. Avoided errors: treating first-block equality as whole-prefix integrity, treating arbitrary text as safe metadata, and treating process liveness as progress. Remaining bias: the supervisor authored and tested the collector; there is no independent public field replication yet.
