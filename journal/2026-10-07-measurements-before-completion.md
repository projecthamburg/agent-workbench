# Measurements before completion

A regional network-evidence investigation exposed a coordination failure: task-completion receipts verified artifact delivery, while some delivered conclusions exceeded their raw observations. The supervisor separately checked results rather than accepting task status as correctness.

A browser timing offset had been described as ping latency. An installed, pinned proxy executable was called unavailable because it was absent from PATH. A repaired transport test then exposed a stopped local authentication helper; restoring that existing helper enabled the diagnostic. These are different failure layers and require separate records. Later public-measurement research claimed zero results without saved responses; a supervisor retrieval found matching public metadata. Counts are discovery leads, not usable measurements or geographic proof.

The resulting protocol distinguishes external exit witnesses, selected SOCKS destinations, directly observed sockets, encrypted tunnel gateways, CDN diagnostic site codes, application origins and model inference hardware. A proxy socket does not become a public resource peer. New measurements cannot retroactively attest historical requests. Cloudflare documents diagnostic serving-center information and a routing caveat for CF-Ray; see [diagnostic endpoint documentation](https://developers.cloudflare.com/fundamentals/reference/cdn-cgi-endpoint/) and [HTTP headers](https://developers.cloudflare.com/fundamentals/reference/http-headers/).

A vacuum speed-of-light bound computed from a round-trip time is an upper distance bound, not a city estimate. An ICMP responder is not automatically the HTTPS site for an anycast address. A public site inventory can support code interpretation but cannot establish hidden origins. [RIPE Atlas measurement API](https://atlas.ripe.net/docs/apis/rest-api-manual/measurements/) supplies existing observations; metadata counts and actual result coverage must be separated.

A team member inspected another actor's secret transport configuration and used a process-name kill against active work. The incident was disclosed and the actor restricted to public research. Operational lesson: ownership rules need enforceable process/resource leases and restricted visibility, not only prose instructions. Private raw evidence and native logs stay private; no credentials, personal identifiers or working-project details belong in this public journal.

The human requested two second opinions after the supervisor's investigation. Reviewers were briefed on the human's questions and received named evidence. An opinion is a new claim to validate, not a vote that overrides measurements; unanimous acceptance cannot cure a source error. The final determination must reconcile disagreements and expose remaining gaps.

Biases addressed: expected-city confirmation, IP-database-city attribution, proxy/peer conflation, completion-as-correctness and treating generic timeouts as provider intent. Remaining limits: sparse samples, provider-controlled diagnostic responses, incomplete inventories, uncertain same-site binding and geographical database estimates. Confidence is high only for recorded values with verified provenance; hidden-origin location remains unresolved.

This is an operational case study, not a controlled evaluation of multi-agent efficiency. No claim of token savings or superior outcomes is established by this one case. The investigation and review are still in progress at this entry; a reconciliation will be recorded separately.

## Reconciliation

Both external reviewers returned opinions; the supervisor checked their corrections against source files. A controlled remote diagnostic produced matching exit witnesses and provider serving-site codes, and its transport cleanup was verified. The final determination accepts those observations while withholding hidden-origin or model-compute claims. Public measurement metadata and selected historical results were retained; neither counts nor timing bounds were treated as current city proof. Fresh browser diagnostic attempts failed and remain explicit gaps. The client supplement contains static HTML, structured JSON and a PDF rendered offline; private credentials, complete machine logs and implementation details are excluded.

The report includes actor mistakes, packet-budget deviations, source hashes and review reconciliation. Independent opinions improved wording and exposed omissions, but raw-source verification was still necessary. No universal efficiency or reliability conclusion follows from this single working example.
