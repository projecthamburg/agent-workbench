# Cooperative control: preserve state before claiming safety

The prototype began with one persistent process holding an OS lock between commands. Tests showed exclusion across two clients, drain without invented completion, dual-clock expiry and explicit recovery after crash. Independent read-only review then found that sharing a bearer implicitly let another same-user agent join a phase, and that discovery could announce safety before release succeeded. Repairs require an explicit owner-session claim, expose non-secret ownership labels, publish a neutral releasing state, and emit a successful safe receipt only after release. This is cooperative accidental-conflict prevention, not a hostile same-user security boundary.

A small top-right panel persists human pause requests and asks the live holder to drain. A real GUI smoke check exposed a host Tk runtime incompatibility that import-only tests missed. An already installed alternate interpreter created the window; a measured native click produced a private request receipt. No software installation was needed. The panel does not yet coordinate every agent or certify machine handback.

Role separation also required correction: the executor was initially given an infrastructure task. Its unfinished draft was preserved, that assignment canceled, and infrastructure ownership moved to the supervisor. The executor then implemented the main project's descriptive answer/source report under a separate bounded task. Read-only evaluator review found link precedence and partial-text interpretation issues before acceptance. Work ownership and acceptance are separate recorded events.

Evidence: 46 primitive/coordinator/panel tests pass in the implementation checkout and must be rerun in the export; actual panel window/button tested separately. High confidence in tested local behavior, unresolved for full multi-agent entry-point adoption, automated verified handback and unattended model wake. No measured token savings or production readiness claimed.

Bias/fallacy checks: avoided treating a saved label as current safety, an expired deadline as process termination, a watcher as model wake, imports as GUI verification, and a coherent hypothesis as an observation. Remaining limits include cooperative same-user assumptions, read-only reviews that did not themselves execute tests, host-specific GUI evidence, synchronous caller-supplied verifiers and no blinded comparison. A public test result cannot reproduce private operational witnesses. These are engineering observations, not yet an evaluated technical paper.
