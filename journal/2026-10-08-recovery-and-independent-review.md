# Recovery and independent review

A supervisor session timeout interrupted coordination while native workers and passive monitors retained their own records. Recovery checked native identity, current usage, acknowledgments, deliverable hashes and collector health separately. A previous usage-limit message was historical; a fresh status check and subsequent worker acknowledgment established that offline work could resume. No live budget was silently extended.

An input repair was accepted after independent source review and regression tests. Its callback checks before each input tier and typing segment, but cannot interrupt a segment already running. PDF inspection claims were narrowed to byte, page and text limits; an asynchronous worker outside its writer deadline cannot be described as elapsed-time bounded. These limits remained in the acceptance record.

Independent review of an additive evidence grader found three problems: a correctly hashed copied payload could be unrelated to the bound answer; malformed evidence containers could crash grading; and boolean/integer equality could create a false ledger match. Revisions required actual correspondence, conservative typed errors and strict integer validation. A later review found malformed scalar paths and classification fields still escaping validation. The final revision passed 42 regression checks and retained 160 prior evidence and interpretation files unchanged. This is tested boundary handling, not exhaustive assurance against arbitrary malformed configuration.

A separate retained-artifact investigation then explained why strict plain-text equality was insufficient. Ordered semantic blocks matched in three saved HTML/Copy-HTML pairs, while interface text, Markdown and citation serialization differed. Some secondary links existed in copied HTML but not copied plain text. Independent recomputation reproduced those findings. It supported a narrowly scoped additional comparison record, not a relaxation of production gates. Historical live Copy-to-turn identity and continuous final-view stability remained unproven.

Presentation review distinguished browser-event timestamps from recorder callback receipt times. A canceled network load occurred with both a wall and a completed frontend answer; neither cancellation nor missing terminal events alone established answer failure, completeness or processing location. The revised package labels time bases, cache flags, service-worker sources, terminal events and capture gaps separately. Review of the rendered exports and source records accepted the corrected artifact while withholding production-route and hidden-origin claims.

A monitor compatibility bug produced a false missing-acknowledgment alert after an actor advanced its ACK to completed. The repair requires the retained timezone-aware acknowledgment time and a separate identity-matched completion receipt. Missing, invalid or future acknowledgment times remain unresolved; changed deliverable bytes remain unverified. Six regression checks covered these boundaries. This recognizes delivery protocol evidence, not correctness.

## Evidence and limitations

Sources: the private acceptance and independent review receipts, bound to delivered artifacts by SHA-256, support these operational observations. Retained review digests include `ce4379185231768952055304abcc58b61204a1119ec4db0e75cadf95d064bf7f` for the artifact-comparison reproduction and `3d0dccea0e7fe9f84ca3f2e6c20c195acf93df73dc616662ab06a9ec851f410a` for the presentation review. Raw working-project evidence and native session identifiers remain private. The general evidence contract is described in [Evidence](../docs/EVIDENCE.md).

Confidence is high for the verified hashes, reported regression outcomes and independently reproduced retained-artifact counts. Confidence is limited for historical event attribution, continuous stability and hidden processing location. The cases were selected operational samples, not a randomized comparison of agents or a demonstration of token savings. Biases addressed include completion-as-correctness, self-hash-as-answer-binding, formatting-inequality-as-generation-failure, static-ancestry-as-live-identity and IP-edge-as-model-origin. Review improved the outcomes but did not remove sampling or missing-evidence limits.
